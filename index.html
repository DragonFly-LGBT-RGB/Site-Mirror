00 / Главная функция

Сайт скачивает сайт — и отдаёт ZIP

Вставь адрес, нажми одну кнопку: обходчик соберёт HTML, CSS, JS, картинки, шрифты, музыку и ассеты из кода, перепишет ссылки на относительные, положит index.html + отчёт и сохранит настоящий ZIP на твоё устройство. Ничего не загружается на сервер — GitHub Pages просто раздаёт статику.

Что качаем

Публичный сайт — через CORS-прокси. Локальный адрес / Radmin VPN (26.x.x.x) — через мост на своём компьютере.

# распакуй site-mirror.zip в одну папку и запусти:
python bridge.py
# вставь в поле выше адрес из консоли: http://127.0.0.1:8787
↓ Скачать bridge.py

Мост использует настоящий движок site_mirror.py v1.4: многопоточно, с автоиндексами, догадками об ассетах, ?embed=true и человечными ошибками. Файлы не покидают твой компьютер.

Свой CORS-прокси / запасной вариант ▾

Публичные прокси иногда недоступны или ограничивают частоту. Если у тебя есть свой Cloudflare Worker / прокси — вставь шаблон, он будет пробоваться первым. Для локальных адресов всё равно нужен «Локальный мост».

Готов. Введи адрес и нажми «Скачать сайт в ZIP».

Про CORS. Браузер с публичной страницы не может напрямую читать чужой сайт — все запросы идут через публичные прокси (цепочка с автопереключением). Прокси не видят приватные сети и иногда ограничены по частоте. Если адрес локальный или прокси не справились — включи «Локальный мост»: это единственный способ получить полное зеркало без ограничений браузера.

Скачанные файлы сразу попадают в архив. Останов можно нажать в любой момент — сохранится то, что успело скачаться.

02 / Интерактивно

Сборщик ZIP прямо на странице

Добавь файлы из репозитория, перетащи свои или укажи адреса — страница соберёт настоящий ZIP (метод Store, UTF-8 имена, корректный CRC32) и сохранит его на устройство. Всё считается локально в браузере.

Источники файлов

Можно комбинировать все три вкладки — файлы сложатся в один общий список.

Файлы запрашиваются с этого же сайта, поэтому на GitHub Pages всё работает. В песочнице предпросмотра сеть может быть недоступна — тогда используй вкладку «С устройства» или готовую кнопку «Скачать .zip».

Перетащи файлы сюда или нажми, чтобы выбрать · можно несколько · ничего не загружается на сервер

Файлы читаются через File API и остаются в памяти вкладки. Это самый надёжный способ собрать ZIP офлайн.

Про CORS. Браузер отдаёт только те адреса, где разрешён cross-origin доступ. Если страница — «рамка» предпросмотра с <iframe>, сборщик повторяет логику v1.4: находит внутренний адрес и пробует ?embed=true. Для произвольного хоста (Radmin VPN, чужой IP) используй python site_mirror.py mirror … --zip — у Python нет ограничений CORS.

04 / CLI

От адреса до архива за три шага

Укажи адрес

IP из Radmin VPN, host:port или полный URL — парсер поймёт любой формат и сам подберёт http/https.

Дождись копирования

Потоки собирают HTML, ассеты, музыку и уровни, переписывают ссылки и пишут _MIRROR_REPORT.md.

Забери ZIP

--zip упакует папку, а serve даст поиграть локально без интернета.

# 1. копия + архив
python site_mirror.py mirror http://26.12.34.56:8080/game/ --threads 20 --zip

# 2. проверить и запустить локально
python site_mirror.py verify my_game
python site_mirror.py serve my_game --port 8000

# 3. PHP/Laravel (osu-web) статикой не копируется
python site_mirror.py repo osu-web

⚠
Честно про ограничения. Инструмент делает статический слепок: страницы за авторизацией, серверный API, WebSocket-мультиплеер и PHP/Laravel-бэкенд в ZIP не оживают. Используй его только для своих или дружеских серверов и с согласия владельца — скрипт не обходит авторизацию и по умолчанию не ходит на чужие хосты.
