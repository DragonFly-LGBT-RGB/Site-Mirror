# site_mirror · v1.4

Скачивает веб-сайт по IP:порту (Radmin VPN) или по URL в локальную папку
и умеет сразу упаковывать результат в ZIP. Всё на стандартной библиотеке
Python 3.8+, без pip-зависимостей.

## Быстрый старт

```bash
python site_mirror.py                 # веб-интерфейс: http://localhost:8765/
python site_mirror.py --cli           # консольный мастер
python site_mirror.py --tk            # старое окно tkinter
```

## Скачать сайт и получить ZIP

```bash
python site_mirror.py mirror 26.12.34.56 8080 --zip
python site_mirror.py mirror http://26.12.34.56:8080/game/ --threads 20 --zip
python site_mirror.py serve my_game --port 8000
python site_mirror.py verify my_game
```

Готовый архив окажется рядом с папкой копии, а внутри неё будет
`_MIRROR_REPORT.md` со списком файлов и ошибками.

## Что нового в v1.4

* Сайты-«рамки» (Arena, CodePen, JSFiddle, редиректы) разворачиваются
  автоматически: находится `<iframe>` и скачивается настоящая страница.
* Поддержка `?embed=true`: если хостинг отдаёт игру только в режиме
  предпросмотра, копия всё равно получает рабочий `index.html`.
* Заголовок `Referer` для площадок, которые требуют его при отдаче страницы.
* `diagnose_page()` по-человечески объясняет «сайта нет», «заглушка nginx»,
  «пустая страница», 404 вместо непонятного сбоя.
* Панель ошибок в веб-интерфейсе, `/api/embed`, счётчик попыток и ошибок.
* `ensure_index()` создаёт главную страницу, даже если игра живёт по `/?embed=true`.
* Фильтр MIME-строк (`image/png`) и CSS-классов при поиске ассетов.

## Полезные флаги

| Флаг | Что делает |
| --- | --- |
| `--threads N` | потоков (по умолчанию 12) |
| `--depth N` | глубина обхода, 0 = без ограничения |
| `--delay S`, `--timeout S`, `--retries N` | вежливость и повторы |
| `--max-mb N`, `--max-files N` | лимиты |
| `--zip` | упаковать папку в ZIP после копирования |
| `--no-assets` | не искать ассеты внутри JS/JSON |
| `--no-rewrite` | не переписывать ссылки |
| `--no-probe` | не пробовать стандартные пути |
| `--no-dir-sweep` | не обходить автоиндексы каталогов |
| `--external` | разрешить другие хосты (осторожно) |
| `--insecure` | игнорировать самоподписанный HTTPS |
| `--extra a,b` | дополнительные URL или файл со списком |

## Ограничения

Статическая копия — это слепок файлов. PHP/Laravel-приложения (например
`ppy/osu-web`) так не копируются: для них есть `python site_mirror.py repo osu-web`.
Страницы за авторизацией, WebSocket-мультиплеер и серверный API в ZIP не оживают.

## Этикет

Используй инструмент только для своих или дружеских серверов и с согласия
владельца. Скрипт не обходит авторизацию и по умолчанию не ходит на чужие хосты.
