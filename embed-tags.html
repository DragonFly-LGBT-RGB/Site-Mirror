Метатеги для красивого Embed в Discord

Скопируй блок в <head> своей страницы. Замени USERNAME на логин GitHub (или запусти python configure.py --user ТВОЙ_ЛОГИН — он сделает это сам).

<!-- ── Open Graph / Discord ──────────────────────────────── -->
<meta property="og:type" content="website">
<meta property="og:site_name" content="site_mirror">
<meta property="og:locale" content="ru_RU">
<meta property="og:title" content="site_mirror — скачать сайт в ZIP">
<meta property="og:description" content="Вставь адрес — сайт сам обойдёт страницы, достанет ассеты из JS/JSON, перепишет ссылки и отдаст готовый ZIP-архив.">
<meta property="og:url" content="https://dragonfly-lgbt-rgb.github.io/Site-Mirror/">
<meta property="og:image" content="https://dragonfly-lgbt-rgb.github.io/Site-Mirror/assets/og-image.png">
<meta property="og:image:secure_url" content="https://dragonfly-lgbt-rgb.github.io/Site-Mirror/assets/og-image.png">
<meta property="og:image:type" content="image/png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="site_mirror — скачивай сайты в один ZIP-архив">

<!-- ── Цвет полоски слева + Twitter fallback ─────────────── -->
<meta name="theme-color" content="#5865F2">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="site_mirror — скачать сайт в ZIP">
<meta name="twitter:description" content="Вставь адрес — получи ZIP со всем сайтом. Страницы, ассеты, переписанные ссылки.">
<meta name="twitter:image" content="https://dragonfly-lgbt-rgb.github.io/Site-Mirror/assets/og-image.png">
<link rel="canonical" href="https://dragonfly-lgbt-rgb.github.io/Site-Mirror/">

Требования Discord: абсолютные HTTPS-ссылки, картинка 1200×630 до 8 МБ, теги в исходном HTML (JavaScript краулер не исполняет), страница доступна без авторизации. Кэш сбрасывается добавлением ?v=2 к ссылке в сообщении.
